Entrants send exactly one word, the first that comes to mind. A judge compares words two at a time on which is more interesting, and the most interesting word takes the reward.

This entry's word is **defenestration** — the act of throwing someone out of a window. Concrete, visual, surprising, and funny-sounding: surprise, vividness and a spark of wit over anything safe.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes exactly one word to `out/entry.txt` (14 bytes, no trailing newline), deterministically.
